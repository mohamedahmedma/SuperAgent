{# Pagination for anything the services return as an `application.dto.Page`. A macro rather than an include, because a window over a listing needs three things a bare include cannot be given cleanly: the page object, the path to link back to, and the filters currently applied. Use it as: {% from "_pagination.html" import pagination %} {{ pagination(rows, ui_prefix ~ "/roster", {"class_code": class_code}) }} `params` must carry every filter the current page is showing. Rebuilding the query by hand in each template is how page two of a filtered roster silently drops the filter and shows the registrar a different set of children under the same heading. Links, not buttons: paging is a read, so it survives with JavaScript off, it is bookmarkable, and the browser's own back button does the obvious thing. #} {% macro pagination(page, path, params={}, noun="rows") %} {% set limit = page.request.limit %} {% set offset = page.request.offset %} {% set first = offset + 1 if page.count else 0 %} {% set last = offset + page.count %} {% set page_number = (offset // limit) + 1 %} {% set page_count = ((page.total + limit - 1) // limit) if page.total else 1 %}
{% if page.total %} Showing {{ first }}–{{ last }} of {{ page.total }} {{ noun }} {# "Page 3 of 40" is the half that tells a registrar scanning for one child in a year group of 600 whether she is anywhere near the end. #} (page {{ page_number }} of {{ page_count }}) {% else %} {# Deliberately not "0 rows". An empty listing and a listing that failed to load look identical, and only one of them is worth investigating. #} No {{ noun }} matched. {% endif %}
{% if page.total > limit %}
  • {% if offset > 0 %} « First {% else %} « First {% endif %}
  • {% if offset > 0 %} Previous {% else %} Previous {% endif %}
  • {% if page.has_more %} {# `has_more` is the DTO's own answer, computed from the total rather than from "did we get a full page" — which is wrong for a final page that happens to be exactly full, and offers a Next that lands on nothing. #} Next {% else %} Next {% endif %}
{% endif %}
{% endmacro %}
