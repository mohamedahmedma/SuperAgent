A batch id is printed by the roster and grades import pages after a preview and after a commit, and can be linked to directly as imports.html?batch=<id>. Reading a report writes nothing.

Batches this browser has opened

This list lives in this browser, not on the server. The service has no endpoint that lists import batches, so a colleague's uploads — and your own from another machine or another browser — will never appear here. Forgetting an id deletes nothing: the batch and its rows stay on the server until they age out, and the id still opens if you paste it again.
