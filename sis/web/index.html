Where things are done
  • Structure — create the academic year, generate year levels and classes, add terms and subjects. Start here.
  • Roster upload — a spreadsheet of children into one class. Columns: student_number, full_name_ar, full_name_en (class_code optional).
  • Guardians — a spreadsheet of parents for children already on the roll. Columns: student_number, phone, a guardian name in either script (alt_phone, relationship, can_view_records optional). One row per adult, so a mother, a father and a big brother for one child are three rows.
  • Marks upload — a spreadsheet of marks for one term. Columns: student_number, subject_code, percentage (or points + max_points).
  • Import batches — what an upload did, row by row, including every rejected line.
