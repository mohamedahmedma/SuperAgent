1 · Where these marks go

A term is required: marks are always stated for one named period. Naming a class narrows the upload, so a sheet sent against the wrong section fails loudly instead of being matched across the whole school.

Subjects on record

For reference only — nothing here is sent with the upload. Every row of the sheet names its own subject_code, and it must be one of these.

2 · The file

.xlsx or .csv, matched by column name and never by position. student_number, subject_code and percentage are the columns this page's template carries; a mark may instead be stated as points with max_points. Extra columns are ignored.

A blank cell means “not graded yet”, and is never 0. Zero is a mark a child can earn, so leave the cell empty for work nobody has marked. Marks are stored exactly as stated — nothing here averages, weights or drops a lowest score.
