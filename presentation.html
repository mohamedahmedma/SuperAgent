A self-reflective architecture.

SuperAgent doesn't just search. It knows how to evaluate and self-correct.

If the Grader model judges the retrieved results irrelevant, the LangGraph state machine automatically triggers a HyDE (hypothetical document) or Step-back transformation to recover the lost context.

Hybrid, precision retrieval.

Semantic understanding alone isn't enough. We hand-built a high-concurrency, lock-protected BM25 sparse vector engine locally.

Milvus runs HNSW (dense semantic) and inverted-index (sparse lexical) retrieval concurrently, then perfectly fuses these two very different result sets using the RRF (Reciprocal Rank Fusion) algorithm.

Complete, coherent context.

Parent-Child Chunking completely eliminates context fragmentation.

Documents are split into 3 tiers. Only the smallest, fine-grained sentences (L3) go into the vector store. Once one is matched, SuperAgent traces back up to wake the larger parent passages (L1/L2) so the LLM gets the full picture.
